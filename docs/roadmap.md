# Roadmap

## Next

- Add a curated dashboard or report built from the dbt marts.
- Publish a short case study with the key acquisition, conversion, and
  navigation findings from a fixed scenario.
- Add automated end-to-end validation for the generator-to-dbt workflow.

## Later

- Introduce scenario comparison and experiment-style analysis.
- Add data contracts and freshness checks suitable for a scheduled deployment.
- Explore forecasting or propensity-modeling in a separate downstream project.

## Non-goals

This project is a reproducible analytics platform, not a production ecommerce
site, customer-data platform, or hosted analytics service.
